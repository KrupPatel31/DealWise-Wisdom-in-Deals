# DealWise — Wisdom in Deals

DealWise is a smart price-comparison and deal discovery platform that helps users find the best prices across multiple stores. It includes visual search, real-time deal tracking, and a gamified Deal Coins rewards system.

## Live Demo
- Website: https://dealwise.in

## Tech Stack
- React 18
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui + Radix UI
- Supabase (Auth, Postgres, Edge Functions)
- TanStack Query
- Framer Motion

## Features
- Multi-store price comparison
- Visual product search
- Barcode scanning
- Coupons and deals discovery
- Deal Coins loyalty system (earn, spend, referrals, daily login)
- Secure checkout + order history

## Getting Started (Local Development)

### Prerequisites
- Node.js (LTS recommended)
- npm (or Bun)

### Install
```bash
npm install
```

### Run (Dev)
```bash
npm run dev
```

### Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
